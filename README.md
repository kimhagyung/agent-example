### Prompt Chaining (프롬프트 연결 기법)

**Prompt Chaining**은 하나의 복잡한 작업을 여러 단계의 순서로 세분화하여 처리하는 방식 

* **동작 원리**: 각 LLM 호출 단계의 출력이 다음 단계의 입력으로 전달되어 순차적으로 처리 
* **제어 방법**: 개발자의 의도에 따라 단계 사이에 프로그램적 검증인 **게이트(Gate)**를 추가할 수 있습니다. 특정 조건을 코딩하여 이를 통과할 경우에만 흐름을 계속 이어가도록 설계 

---

### Gates (검증 단계)

**Gate**는 전체 프로세스가 의도한 방향으로 잘 진행되고 있는지 확인하는 품질 관리 지점 

* **역할**: 워크플로우 중간에서 프로세스의 상태를 점검 
* **결과 처리**: 위 그래프의 구성에 따르면, 검증 단계를 통과하지 못할 경우 프로세스는 그대로 종료되거나 흐름에서 이탈하게 된다.
