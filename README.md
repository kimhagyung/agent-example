## AI Agents #19 Tutor Agent

### **1. .env 환경 파일 구성**

프로젝트 실행을 위해 아래의 API 키 설정이 필요
* `OPENAI_API_KEY`: LLM 추론 및 에이전트 브레인 역할
* `FIRECRAWL_API_KEY`: 웹 데이터 추출 및 학습 자료 수집용

---

### **2. 학습 목표**

사용자의 학습을 보조하고 가이드하는 **Tutor 에이전트(Tutor Agent)**의 구조를 설계하고 구현한다.
* 지식 검색, 요약, 질의응답을 통합한 교육용 에이전트 구축
* 실시간 웹 크롤링을 활용한 최신 정보 기반의 튜터링 로직 습득

---

### **3. 실행 방법**

에이전트를 로컬에서 실행하고 전용 UI를 통해 테스트하는 절차

1. **서버 실행**: 터미널에서 아래 명령어를 입력하여 LangGraph 개발 서버를 구동한다.
   ```bash
   uv run langgraph dev
   ```
2. **UI 접속**: 서버가 정상 동작하는 확인 후, [Agent Chat UI](https://agentchat.vercel.app/)에 접속한다.
3. **에이전트 선택**: 접속 후 에이전트 목록에서 이름을 **tutor**로 설정하여 대화를 시작한다.

> **주의**: 반드시 로컬 서버가 실행 중인 상태여야 UI에서 에이전트와 정상적으로 통신할 수 있다.

---

### **4. 주요 특징**

* **Firecrawl 통합**: 정적인 데이터에 머무르지 않고, 최신 웹 콘텐츠를 크롤링하여 학습자에게 정확한 정보를 전달함.
* **상호작용 설계**: 단순 답변을 넘어 학습자의 이해도를 체크하고 단계별로 설명하는 튜터링 프로세스 구현.
