# #17 Testing Agents

### 환경 설정

* **.env 환경 파일 구성**: 이전 섹션과 동일한 설정을 그대로 사용.

### 목표

우리가 만든 **Workflow, Agent, Graph**들을 `PyTest`를 이용해 테스트하는 법을 배운다

* Graph 테스트의 처음부터 끝까지 전체 프로세스 습득
* **AI 모델을 활용한 테스트**: Graph가 제대로 작동하는지 검증해 주는 '조력자 AI' 모델 사용법 학습

---

### 테스트 이유 

에이전트는 단계가 복잡해질수록 예상치 못한 경로로 빠질 수 있다.
<br> `PyTest`를 통해 각 노드(Node)가 상태(State)를 올바르게 업데이트하는지, 최종 목적지까지 잘 도달하는지 자동 검증한다. 
### 실행 방법

터미널에서 아래 명령어를 입력하여 테스트를 실행
(vv는 상세를 의미)
```bash
uv run pytest tests.py -vv

```


### AI 모델로 AI를 테스트하기 (LLM-as-a-Judge)

단순히 텍스트가 일치하는지(==) 비교하는 건 에이전트 테스트에서 한계가 있음. (답변이 매번 조금씩 달라지니까!)

그래서 테스트 전용 AI 모델을 따로 설정해서, 내 에이전트의 답변이 논리적으로 타당한지, 사용자의 의도에 정말 부합하는지를 판별하는 고급 기법을 사용함.

핵심 컨셉: 또 다른 LLM, 즉 '제3의 AI'를 불러와서 내 AI를 평가하게 만드는 것.

Judge(평가자): 여러 명의 평가자를 설정해서 내 에이전트의 Response가 객관적으로 괜찮은지 점수를 매기거나 합격/불합격을 판단함.
